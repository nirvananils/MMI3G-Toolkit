# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [1.2.1] - 2026-10-20

### Fixed
- Startup splash ("Viel Spaß mit den Dinosauriern") could fail to appear, so
  the main window showed right away. The splash is now forced to the front,
  falls back to a normal window if the borderless one is not mapped, and
  stays visible for at least 2.5 s. The main window is built after the splash
  is painted and stays hidden until the splash closes.

## [1.2.0] - 2026-10-20

### Changed
- Synced with upstream `dspl1236/MMI3G-Toolkit`: shared completion trap and
  timeout hardening in `core/platform.sh` for `running.png` modules,
  time-bounded diagnostic dumps in `system-info` (no more hangs on a stuck
  utility), README module table and hardware section updates, and
  `docs/MODULE_HARDENING.md`, plus new shell-robustness tests.

### Added
- Dinosaur app icon (`assets/icon.ico` + `icon.png`, generated by
  `packaging/make_icon.py`): a cheeky grinning brontosaurus with a stuck-out
  tongue. Shown in the main window, the About and help windows, and baked into
  the `.exe` (via the PyInstaller spec `icon=` and bundled `assets/`).
- Per-module "Anleitung zu diesem Modul…" button on the SD-Karte tab and a
  per-tool "Anleitung öffnen…" button on the Firmware-Tools tab. Each opens a
  standalone, scrollable window with a German description plus a step-by-step
  how-to (built from the module metadata / tool docstring and curated
  `MODULE_HELP` / `TOOL_HELP` notes).

## [1.1.0] - 2026-10-20

Codename: **Dinosaurier Generation**.

### Added
- Graphical SD-card builder (`builder/gui.py`), a Tkinter front end over the
  existing `build_sd.py`, launched via the root `mmi3g_toolkit.py`. It
  discovers modules, filters them by target platform, resolves prerequisites,
  and streams build output into a log pane.
- GUI organised into task tabs (`ttk.Notebook`): **SD-Karte**,
  **Firmware-Tools**, **Splash-Screen**, **Release / Git**.
- SD-Karte module picker is a `ttk.Treeview` with categories as collapsible
  parent rows and a ☐/☑ selection column, plus a detail panel showing the
  focused module's status, compatibility and description.
- Firmware-Tools tab runs any `tools/*.py` utility (plus
  `builder/generate_manifest.py`) with arguments and a `--help` button, each
  with a German description and its docstring. Tools run in-process (`runpy`),
  so they work from the bundled `.exe` as well as from source. Optional
  auto-analysis scans a firmware folder for known files (`.ifs`, `.efs`,
  `lsd.jxe`, `dsi.jar`, `metainfo2.txt`) and runs the matching
  analysis/extraction tools; patchers that need explicit targets stay manual.
- Splash-Screen tab converts any image into an 800x480 `startup_generic.png`
  (cover-fit, centered, zoom slider, live preview; requires Pillow).
- Release / Git tab shows the version, opens the changelog, and drives the
  commit / tag / push release workflow (push actions confirm first).
- **Info** menu bar with Über (About dialog), README, Changelog, GitHub,
  Releases and MIT license entries; hover tooltips on the main action buttons.
- Version codename (`__codename__` in `builder/version.py`), shown in the
  window title and About dialog.
- Startup splash screen with a cartoon dinosaur and the heading "Viel Spaß mit
  den Dinosauriern"; auto-closes, click to skip.
- `builder/version.py` as the single source of truth for the toolkit version,
  surfaced in the GUI and used to stamp the Windows `.exe`.
- Windows packaging: PyInstaller spec (`packaging/mmi3g-gui.spec`) and build
  script (`packaging/build_exe.ps1`) producing a standalone
  `MMI3G-Toolkit-Builder.exe` with `modules/`, `core/` and `tools/` bundled.
- Release automation: `.github/workflows/release-exe.yml` builds the `.exe` on
  every main push (as an artifact) and, on a `v*` tag, attaches it to the
  matching GitHub release.
- Release process documentation in `docs/RELEASING.md`.

## [1.0.0] - 2026-04-01

### Added
- Initial public toolkit: 26 modules, Python CLI builder (`build_sd.py`), web
  app, firmware tooling, and research documentation.
